# This is NOT the HIBP corpus. It is a deliberately small embedded fallback so
# that PasswordPolicy — which fails CLOSED without a breach set — has something
# to check against on a machine with no network and no downloaded corpus.
# Shipping the real list means either a 30GB download at build time or a
# k-anonymity API call on the signup path; §0.3 rule 1 forbids inventing what

# below is therefore 12+ characters — which is exactly the set a naive
# "make it longer" user lands on, and exactly what an attacker's dictionary
# starts with.
#
